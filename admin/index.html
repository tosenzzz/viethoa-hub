Đăng nhập bằng GitHub token

Trang này sửa thẳng qua GitHub API. Mỗi lần lưu là một commit, GitHub Actions build lại và đẩy lên site sau khoảng 1–2 phút.

Tạo token thế nào?
  1. Mở GitHub → Fine-grained token.
  2. Repository access: Only select repositories → chọn repo source.
  3. Permissions: Contents: Read and write, Actions: Read-only (để xem tiến độ build).
  4. Tạo rồi dán token vào ô trên.
